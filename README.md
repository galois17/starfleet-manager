## Starfleet Command: Java Polymorphism Demonstration

This project serves as an educational example to demonstrate **Runtime Polymorphism** and **Method Overriding** in Java using a practical, service-oriented theme.

The application simulates a Starfleet Maintenance Bay that can run diagnostics on different types of spaceships (`StarshipCruiser`, `Starfighter`) without knowing their specific class at compile time.
